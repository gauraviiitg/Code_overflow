# Documentation matrix (internal)

| Product type | Usual HS chapter | Extra docs Western buyers ask for |
|--------------|------------------|-----------------------------------|
| Textiles & home | 50–63 | Composition labels, OEKO-TEX if claimed, care symbols |
| Handicraft (metal/ceramic) | 69–83 | Lead/cadmium test reports for food contact; wood fumigation |
| Spices & agro | 07–12 | COA, moisture/aflatoxin where applicable, FDA prior notice (US) |
| Marble & stone | 68 | Weight/packing diagram, anti-dumping awareness (market-specific) |

Always align invoice description with broker’s preferred wording before ETD.
